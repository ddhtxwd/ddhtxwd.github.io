课程表

v1.0.20261023 · 应用目录 /class_table

课程表是一款常驻桌面的课程安排应用：上电后自动开启配置热点，用手机网页即可填写 WiFi 与每周课程；连接路由器后通过 SNTP 校准时间，并在 4.2 英寸三色墨水屏（400×300，黑/白/红）上显示课程表格、当前/下一节课和电池电量。

功能简介

  • 网页配网：设备常开 ClassTable-XXXX 热点，手机连接后打开 http://192.168.4.1/，可扫描或手动输入 WiFi，支持开放网络与加密网络。
  • 课程表编辑：网页按“星期 × 节次”生成表格，格子内容格式为 课程@教室；可切换周一~周五或周一~周日，最多 10 节课。
  • 自动对时：连接 WiFi 后通过 SNTP 获取网络时间并写入 RTC，默认东八区；失败每 60 秒重试，成功后每 6 小时再校准一次。
  • 课程高亮：今天所在的星期表头标红；当前正在上的课在格子外加红色边框、课名标红，顶部同时显示“正在上/下节”。
  • 配置界面：按 OK 键切换到配置页，直接查看当前热点名称、配置地址和联网状态，方便手机重新配网。
  • 电池电量：通过 GPIO2 使能、GPIO1 采样电池电压（分压系数 1/2），课程表页与配置页显示图标和百分比，低于 15% 变红。
  • 自动刷新：默认每 60 秒检查一次，时间或状态变化才重绘；间隔可在 30~3600 秒之间调整，减少墨水屏刷新次数。
  • 断网可用：已校准的时间在断网后继续走时；WiFi 掉线后每 60 秒自动重连，恢复后立即对时并刷新。

安装与启动

  1. 用 Chrome / Edge 打开墨水屏应用管理器并连接设备。
  2. 在应用中心先安装必装驱动（提供 driver/epd4in2b.py 和 GB2312-12.fon 中文字库），再安装课程表，文件会写入设备 /class_table 目录。
  3. 点亮课程表卡片上的星标，把它设为默认应用（写入根目录 device.json），重启后开机自动进入课程表。
  4. 想开机跳过课程表进入应用管理器：上电时按住上键或下键不放（GPIO40/39），开机检测到按键就会启动管理器。

课程表依赖驱动中的屏幕与中文字库，未安装驱动时会出现找不到 epd4in2b 或无法显示中文的问题。

首次使用：连接热点并配网

  1. 首次上电时 config.json 中没有 WiFi 记录，设备会开启热点 ClassTable-XXXX，其中 XXXX 是芯片唯一 ID 后两字节的十六进制。热点默认开放（无密码），运行期间一直保持开启。
  2. 用手机连接该热点。多数手机会自动弹出配置页；如果没有弹出，打开浏览器并输入 http://192.168.4.1/。
  3. 在网络页填写 WiFi 名称与密码，也可以点“扫描”后按提示输入序号或名称。ESP32 只支持 2.4G 网络，开放网络密码留空，隐藏 SSID 需手动输入完整名称。
  4. 同一页还可以设置 NTP 服务器（默认 ntp.aliyun.com）和时区（默认 UTC+8）。
  5. 点底部保存并应用。设备会保存配置并尝试连接路由器，最多等待约 20 秒；成功后自动对时并刷新课程表。

如果保存后手机热点连接短暂断开，通常是设备连接路由器时热点信道随之切换，重新连接 ClassTable-XXXX 并刷新页面即可。热点在连接成功后不会关闭，方便随时改配置。

填写课程表

  1. 打开课程表页，先选择每周显示周一~周五或周一~周日。
  2. 在作息时间中修改每节名称、开始时间和结束时间，点“+ 添加一节”最多到 10 节；删除中间一节时，该节及之后的课程会自动上移。
  3. 在下方表格中按“星期 × 节次”填写课程，格式为 课程@教室，例如 高等数学@A101。只写课程名也可以，留空表示没课。
  4. 点保存并应用，设备会重新渲染课程表。

网页每天高亮当前星期列；墨水屏上课程格高度足够时分成两行显示课程名与教室，空间不足时合并为一行并按宽度截断。

屏幕界面

课程表页

  • 左上：日期与星期，例如 10月23日 周五；尚未对时时显示“尚未对时”。
  • 右上：大号数字显示时:分，旁边是电池图标与百分比。
  • 第二行：显示“正在上 …”“下节 …”；没有 WiFi 时显示“未连接 WiFi，时间未同步”；当天没课时显示“今天没有课程了”。
  • 表格：第一列是节次与开始时间，其余列为周一至周日（或周一至周五）；今天表头红色，正在上的课用红框和红字标出。
  • 底部：提示“按 OK 键进入配置界面”。

没有校准时间时无法判断当前节次，课程表仍会显示内容，但不会高亮当前课程。

配置界面

  • 大号显示当前热点名称和配置地址 http://192.168.4.1/，手机连不上时可以对照输入。
  • 下方依次显示 WiFi 名称与 IP、当前时间、对时状态、电池电压/百分比和剩余内存。
  • 底部提示“按 OK 键返回课程表”。

按键操作

三个按键都是低电平触发、内部上拉，按键短按生效：

按键引脚功能
OKGPIO0课程表 ↔ 配置界面
上GPIO40课程表 ↔ 配置界面（等同 OK）
下GPIO39立即对时并刷新屏幕

GPIO0 通常对应开发板上的 BOOT 键。若实际 OK 键接在其他引脚，修改 class_table.py 顶部的 KEY_OK 即可。开机时按住上键或下键不放，可跳过课程表进入应用管理器。

自动对时与刷新

  • 对时：连接 WiFi 后用 SNTP（UDP 123）向 NTP 服务器取时间，按设置的时区换算后写入 RTC；默认服务器 ntp.aliyun.com，默认东八区。
  • 重试：未同步成功时每 60 秒重试；同步成功后每 6 小时再校准一次；WiFi 掉线时每 60 秒自动重连。
  • 刷新间隔：默认 60 秒，可在设置页调为 30~3600 秒。设备只在时间分钟数或联网/对时状态变化时重绘，屏幕时间精度为分钟。
  • 网页保存后：设备先应用新配置、连接 WiFi 并尝试对时，随后刷新屏幕；手机页面会短暂显示“已保存，设备正在应用”。
  • 墨水屏特性：三色墨水屏只支持整屏刷新，刷新需要数秒并伴随闪黑，属于正常现象；调大刷新间隔可减少刷新次数。

电池电量

  • 采集时 GPIO2 输出高电平，等待 20 ms 后读取 GPIO1 的 ADC，分压系数为 1/2，因此电池电压 = ADC 引脚电压 × 2；采集结束后 GPIO2 拉低。
  • 开机、运行中每 60 秒、以及按 OK 进入配置界面时都会采样一次。
  • 课程表页和配置页显示电池图标与百分比；电量不高于 15% 时图标和数字变红。配置页与网页还会显示电压，例如 4.02V。
  • 百分比默认按 1S 锂电池（3.0V~4.2V）放电曲线估算，仅供参考；使用其他电池时请修改 class_battery.py 中的 _CURVE。
  • 没有电池或采样电路时显示 -- / “未检测”，不影响其他功能。

配置文件

配置保存在设备 /class_table/config.json。网页保存后立即生效并写入文件；直接编辑文件后需要重启（软复位）才会重新读取。文件不存在或格式错误时使用默认配置。

字段默认值说明
wifi.ssid空路由器名称，配网成功后写入
wifi.pwd空WiFi 密码，开放网络为空
ntp.hostntp.aliyun.comNTP 服务器地址
ntp.tz8时区偏移（小时），范围 -12~14
ap_pwd空配置热点密码；至少 8 位，不足 8 位按开放热点处理
days5每周显示天数，5 或 7
refresh60自动刷新间隔（秒），范围 30~3600
periods8 节作息列表，最多 10 节，每项含名称、开始、结束时间

课程表键的星期为 1~7（周一为 1），节次从 1 开始，例如 1_1 表示周一第 1 节。示例（只列出两节）：

常见问题

手机连上热点却打不开配置页

确认连接的是 ClassTable-XXXX，热点默认没有密码；在浏览器地址栏输入 http://192.168.4.1/，不要当作搜索关键词。部分手机在热点无外网时会自动切回移动数据，请关闭“自动切换网络”，或在系统提示“此网络无法上网”时选择保持连接。

保存后连接不上路由器

ESP32 只支持 2.4G WiFi，请确认没有选到 5G 频段；核对名称大小写与密码；路由器开启 MAC 白名单或防蹭网时需先放行设备；隐藏 SSID 要手动输入完整名称。失败时网页状态仍显示“未连接”，热点不会关闭，可以重新进入配置页修改后再次保存。屏幕继续显示课程表，但时间不会更新。

时间一直不对或显示“尚未对时”

确认路由器可以正常上网，且没有屏蔽 NTP（UDP 123 端口）；检查 NTP 服务器和时区是否填写正确（默认东八区）。设备每 60 秒自动重试，也可以按下键立即重试。已经对过时的时间在断网后会继续走时，只是暂时不再校准。

课程没有显示或当前课没有高亮

检查“每周显示天数”是否包含该星期；课程要填在正确的“星期 × 节次”格子里，格式为 课程@教室；确认节次时间已填写且开始时间早于结束时间。当前课程高亮依赖已校准的时间，未对时或不在上课时间段内不会高亮。

想更换 WiFi 或清空配置

连接热点后打开配置页，在网络页修改 WiFi 名称和密码并保存即可；清空 WiFi 名称后保存，设备会断开路由器，但配置热点仍然开启，方便重新配网。课程、作息和显示设置会保留。

热点密码怎么设置

默认是开放热点。在设置页填写“配置热点密码”，至少 8 位；不足 8 位会被按开放热点处理。修改后手机需要重新连接热点。

电量显示 -- 或不准确

显示 -- / “未检测”说明 ADC 没有读到有效电压，检查电池采样电路、GPIO1/GPIO2 接线和电池是否接入。百分比按 1S 锂电池曲线估算，配置页和网页会同时显示电压，可据此判断；使用其他电池时需调整电压曲线。

按键没有反应

按键为低电平触发并启用内部上拉，短按才会生效。OK 键默认使用 GPIO0（通常是 BOOT 键）；如果开发板的 OK 键接在其他引脚，请修改 class_table.py 中的 KEY_OK。按键被卡住或引脚接错时也会没有反应。

怎么退出课程表回到应用管理器

重新上电时按住上键或下键不放，开机检测到按键会跳过默认应用直接进入应用管理器；也可以在应用管理器终端发送 Ctrl-C 中断应用后重新操作。

安装后开机没有自动进入课程表

需要在应用中心点亮课程表卡片上的星标“设为默认应用”（写入根目录 device.json），再重启设备；同时确认“必装驱动”已安装，否则会因找不到 epd4in2b 或中文字库而无法显示。

刷屏慢、有闪黑和残影

三色墨水屏只支持整屏刷新，每次重绘需要数秒并伴随闪黑，属于正常现象；残影会在下一次整屏刷新后消失。想减少刷新可把刷新间隔调大（如 120、300 秒），屏幕时间的刷新精度也会随之降低。
