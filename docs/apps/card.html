电子桌牌

v0.1 · 应用目录 /card

电子桌牌是一块常驻桌面的姓名牌：开机后先显示电脑通过 USB 下发的卡片画面（/card/preview.img）；还没有收到过图片时，按 /card/config.json 里的“姓名 / 职务 / 单位 / 标语”画一张默认桌牌。显示完成后应用立即退出、墨水屏进入深度睡眠，画面靠电子墨水保持，断电不消失；REPL 随之空闲，随时可以从网页再次下发新卡片，不需要先对设备做任何操作。

← 跳转到电子卡编辑器（需要断开应用管理器的端口）

功能简介

  • 卡片显示：显示 400×300 黑/白/红三色位图，内容由电脑端“电子卡网页设计器”制作（模板、文字、手绘、导入图片）。
  • 默认桌牌：未收到图片时显示红条 + 大字姓名 + 职务 / 单位 / 标语的默认版式，内容改自 config.json，无需写代码。
  • USB 下发：Chrome / Edge 打开网页设计器即可传输，全程不需要 WiFi，也不需要设备上装额外软件。
  • 不占串口：显示完就退出并让墨水屏深度睡眠，网页要下发时直接接管 REPL 即可，无需先打断桌牌。
  • 开机重显：上电自动显示最近一次下发的卡片，长期摆放零功耗。

安装与启动

  1. 用 Chrome / Edge 打开墨水屏应用管理器并连接设备。
  2. 在应用中心先安装必装驱动（提供 driver/epd4in2b.py 屏幕驱动与中文字库），再安装电子桌牌，文件会写入设备 /card 目录。
  3. 点亮桌牌卡片上的星标，把它设为默认应用（写入根目录 device.json），重启后开机自动显示桌牌。
  4. 想开机暂时跳过桌牌进入应用管理器：上电时按住上键或下键（GPIO40/39）不放。

做一张卡片并下发

  1. 电脑用 Chrome / Edge 打开电子卡网页设计器（pc/index.html，双击直接打开即可；若提示安全上下文不满足，只有桌面版 Chrome / Edge 有 Web Serial，手机打不开）。
  2. 选一个模板填内容，或用“空白手绘”画一张、导入 PNG/JPG 照片。
  3. USB 连接设备，点连接设备；网页自动中断设备上正在跑的程序并自检，提示“设备就绪”即成功。
  4. 点下发到墨水屏：网页把接收程序现场下发给设备，再逐行传输图片（进度走到 100%），存为 /card/preview.img 并整屏刷新，刷新约需 15～40 秒，期间屏幕闪黑，别拔 USB。
  5. 以后想换卡片，重复第 2、4 步即可；每次上电显示的都是最近一次下发的画面。

下发不依赖设备上的这个应用：接收程序由网页现场下发执行，固件里没有 card.py 也能传图；桌牌应用负责的是“再次上电时自动把画面显示出来”。

默认桌牌版式

  • 顶部：黑色边框 + 一条红色装饰线。
  • 姓名：32px 大字居中，超长自动截断加“..”；红条上不放字（黑红同点显示成黑色）。
  • 职务：24px 居中；单位：16px 居中。
  • 标语：12px 红字；底部两行小字提示当前是默认桌牌、以及如何用 USB 下发图片。

配置文件

/card/config.json 的字段只在“还没收到过下发图片”时用于默认桌牌；一旦有 preview.img，开机直接显示图片，配置不再上屏。可在应用管理器的文件视图里编辑，保存后点状态栏的“软复位”（或在终端按 Ctrl-D）重启生效——配置只在启动时读取一次。

{"姓名": "陈小明", "职务": "三年级 2 班", "单位": "实验小学", "标语": "保持好奇 · 快乐创造"}

图片保存位置：永远写入 /card/preview.img（目录不存在会自动创建，建不了才退回根目录）；早期版本存在根目录的旧图，在新一次下发成功后会被自动清掉。

常见问题

下发了，但开机显示的还是默认桌牌

说明上一次下发没有成功保存完整图片（必须正好 30000 字节）。回网页看日志：进度是否走到 100%、有没有“✓ 下发完成”；中间出现过红色错误行的，排除原因后重发一次。设备正在整屏刷新（15～40 秒）时不响应串口，等画面定住后再下发。

网页连不上 / 操作一直超时

常见原因：设备正在刷屏（等画面稳定后重试）；串口被 Thonny 等其它上位机占用（先关闭）；设备上没跑 MicroPython。网页日志会给出“设备实际回复”摘要，按提示处理即可；刷新网页或给设备重新上电再连一次一般能恢复。

屏幕上的颜色和原图不一样

墨水屏只有黑、白、红三色，网页会把彩色和灰度图用抖动算法转成三色：深色归黑、偏红且够艳的归红，其余归白，近看会有细密网点，属正常。

提示“画面几乎是白屏”被拦下

当前画面几乎没有墨，发过去只会得到一块白屏。按页面列出的原因排查（比如字色选了白、图层被隐藏、内容还没画完），确认无误后再点一次“下发”会强行发送。

想临时用 USB 干别的 / 回到应用管理器

桌牌显示完就退出、REPL 是空闲的，网页下发会自行接管，不用先“停机”。想进应用管理器：重新上电时按住上键或下键不放；或在终端按 Ctrl-C 回到 REPL。

画面发淡、有上一张卡的残影

三色屏只有整屏刷新，残影会在下一次整屏刷新后消失：重新下发一次，或给设备重新上电让桌牌重显即可。
